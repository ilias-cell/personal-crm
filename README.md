# Личная CRM

Приложение для ведения контактов людей, которых знаешь лично: кто это, откуда знакомы, телефон, почта и заметки после разговоров. Идея и границы продукта — в `specs/01-продуктовая-идея.md`.

## Что умеет

- Список всех контактов, новые сверху
- Поиск по имени: без учёта регистра, «е» и «ё» считаются одной буквой, слова можно вводить в любом порядке
- Добавление контакта: имя (обязательно), кто это, откуда знакомы, телефон, почта
- Карточка контакта с лентой заметок: каждая заметка сохраняется с датой, новые сверху
- Редактирование контакта

Удаления контактов и заметок нет — это сознательное решение.

## Что нужно на компьютере

- [Node.js](https://nodejs.org) 20.12 или новее
- [pnpm](https://pnpm.io)
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) — в нём работает база данных

## Первый запуск

1. Создайте файл с настройками и заполните в нём значения:

   ```bash
   cp .env.example .env
   ```

   Имена переменных уже есть в `.env.example`. Пароль придумайте любой, порт базы — `5433`. `DATABASE_URL` — это строка подключения целиком: `postgresql://ПОЛЬЗОВАТЕЛЬ:ПАРОЛЬ@localhost:5433/ИМЯ_БАЗЫ`.

2. Запустите базу данных:

   ```bash
   docker compose up -d
   ```

3. Установите зависимости и создайте таблицы:

   ```bash
   pnpm install
   pnpm db:migrate
   ```

4. Запустите приложение:

   ```bash
   pnpm dev
   ```

5. Откройте в браузере <http://localhost:3001>.

## Обычный запуск

Когда всё уже настроено, достаточно двух команд:

```bash
docker compose up -d
pnpm dev
```

Остановить приложение — `Ctrl+C` в терминале. Остановить базу — `docker compose stop` (данные сохраняются).

`pnpm dev` — режим разработки: удобен, пока приложение меняется, но страницы открываются медленнее. Чтобы пользоваться приложением на полной скорости:

```bash
pnpm build
pnpm start
```

После изменений в коде `pnpm build` нужно выполнить заново.

## Тестовые данные

```bash
pnpm db:seed
```

Команда добавляет 1000 выдуманных контактов и заметки к ним. Она работает только на пустой базе: если в базе уже есть хотя бы один контакт, команда ничего не меняет и сообщает об этом. Телефоны начинаются с несуществующего кода `000`, почта — на домене `example.com`, так что случайно позвонить или написать реальному человеку не получится.

## Как проверить руками

1. Откройте <http://localhost:3001> — виден список контактов и их общее число.
2. Нажмите «Добавить контакт», заполните имя, нажмите «Добавить контакт» — новый контакт появился первым в списке.
3. Введите его имя в поиск — список сузился до него. Откройте карточку.
4. Напишите заметку, нажмите «Сохранить заметку» — она появилась в ленте с датой. Обновите страницу — заметка на месте.
5. Откройте тот же адрес в другом браузере — там те же контакты и та же заметка.

## Команды

| Команда | Что делает |
| --- | --- |
| `pnpm dev` | Запускает приложение в режиме разработки на порту 3001 |
| `pnpm build` | Собирает быструю версию приложения |
| `pnpm start` | Запускает собранную версию на порту 3001 |
| `pnpm db:migrate` | Создаёт и обновляет таблицы в базе |
| `pnpm db:generate` | Создаёт файл миграции после изменения `src/db/schema.ts` |
| `pnpm db:seed` | Наполняет пустую базу тестовыми контактами |
| `pnpm lint` | Проверяет код линтером |
| `pnpm typecheck` | Проверяет типы TypeScript |

## Как устроено

- **Next.js (App Router), TypeScript** — страницы и серверный код в `src/app`
- **Tailwind CSS и shadcn/ui** — интерфейс; готовые компоненты лежат в `src/components/ui`
- **PostgreSQL в Docker** — описан в `compose.yaml`, слушает порт 5433
- **Drizzle** — схема таблиц в `src/db/schema.ts`, миграции в папке `drizzle`

К базе обращается только сервер: браузер получает готовые страницы и отправляет формы. Список и карточки читаются из базы при каждом открытии, без кеша, поэтому в любом браузере видны одни и те же актуальные данные.

Порты выбраны так, чтобы не мешать другим проектам на этом компьютере: приложение — 3001, база — 5433.

Приложение и база доступны только с этого компьютера (адрес `127.0.0.1`). Входа по паролю в приложении нет, поэтому в домашнюю или публичную сеть оно не выставлено: с телефона или другого компьютера его не открыть. Это задаётся параметром `-H 127.0.0.1` в командах `dev` и `start` в `package.json`.

Next.js умеет отправлять своим разработчикам анонимную статистику использования. Здесь она отключена: в командах `package.json` стоит `NEXT_TELEMETRY_DISABLED=1`.

## Если что-то не работает

- **«Не удалось загрузить данные»** — не запущена база. Запустите Docker Desktop и выполните `docker compose up -d`.
- **`DATABASE_URL is not set`** — нет файла `.env` или в нём не заполнена строка подключения.
- **Порт 3001 занят** — приложение уже запущено в другом окне терминала. Закройте его или остановите там же через `Ctrl+C`.

# Tasks

Порядок работы в каждой задаче с тестами:

1. Сначала тест. Запустить `pnpm test` (или `pnpm test:e2e`) и увидеть, что он красный.
2. Потом код. Тест зелёный.

Один тест — один сценарий из спеки; имена тестов на английском. Ссылки «решение N» ведут в `design.md`.

Нужен запущенный `docker compose up -d`: Postgres и Mailpit.

Между группами 2 и 5 e2e-тесты красные: схема уже требует владельца, а вход ещё не готов. Их чинит группа 5.
